# Nyaya Logic as an Inference Engine

## Project Description

This project presents a simplified computational interpretation of
Nyaya inference as a rule-based inference engine.

The system accepts facts, inference rules, and a query. It applies
forward chaining to determine whether the query can be derived.

The project also generates a five-member explanation inspired by
the structure of Nyaya inference:

1. Pratijna
2. Hetu
3. Udaharana
4. Upanaya
5. Nigamana

## IKS Concept

Nyaya Logic - Anumana (Inference)
